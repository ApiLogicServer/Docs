!!! pied-piper ":bulb: Project Studio"

      GenAI-Logic-web-studio enables **Business Analysts and Product Managers** to build **enterprise-class systems** — from one prompt or your existing database, *5 rules instead of ~200 lines of code*. If that's enough, you're done. If it isn't, hand the *same project* to Dev — not a rewrite, not a re-platform — for extension and deployment.

      That hand-off is the point. Low-code platforms hit a wall when a citizen-built app outgrows the canvas: the artifact is a proprietary black box IT can't take over, so it either gets thrown away and rebuilt from scratch, or lives on ungoverned as shadow IT because nobody will touch it. Web Studio never creates that wall — there's no black box to hand over. It's a real data model, real declarative rules, real generated code, the whole way through.

      The goal here isn't a demo — it's an **enterprise-class** system you can trust, maintain, and grow into:

      1. **User Friendly** — no database design or screen painting to learn; it's all automated from natural language.
      2. **Dev Friendly** — the exact same project opens in the IDE developers already use (VSCode, PyCharm) — same editor, same debugger, same AI assistant. Nothing to relearn, nothing to migrate.
      3. **DevOps Friendly** — standard containers; deploy to cloud or on-prem.
      4. **Enterprise Friendly** — pluggable security (SQL or Keycloak), full REST API, event/messaging integration (Kafka, webhooks) — built in, not bolted on.

      **No shadow IT. No rewrite. One project, from prompt to production.**
